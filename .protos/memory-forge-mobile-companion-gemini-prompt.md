# Gemini 图生图提示词：Memory Forge 移动伴侣

将 `memory-forge-mobile-companion.png` 作为参考图上传，再使用以下提示词：

```text
请基于参考图，为“Memory Forge / 记忆锻造”设计一张高保真的移动端产品原型展示图。

产品定位：本地优先的 AI 编程助手会话管理器。用户在电脑上运行 Claude Code、Codex、OpenCode、Grok 等 CLI，会在手机上查看多个工作区和 Agent 会话、继续输入、控制远程终端，并查看或恢复历史消息修改。

输出构图：
- 1536×1024 横向画布。
- 深色、安静、专业的开发者工具背景。
- 并排展示三台现代手机，完整显示屏幕，不裁切，不倾斜到难以阅读。
- 第一台是 Workspaces / 会话总览。
- 第二台是 Agent / 远程继续会话。
- 第三台是 Memory / 修改审计与终端。
- 这是一张产品 UI 原型图，不是营销海报；手机界面是绝对视觉主体。

视觉语言：
- 不复制 Paseo 的代码、Logo 或具体组件，只借鉴“桌面与手机功能一致、手机单任务导航”的产品思想。
- 基础色为偏绿色的炭黑：背景 #0f1413，表面 #151b19，高层表面 #1d2522，边框 #303a36。
- 主文字 #e7ede9，次要文字 #93a099。
- 主强调色 #72d69f，仅用于在线、运行中、发送和成功状态。
- 辅助蓝 #82a9ff 用于用户消息和选中状态；琥珀 #e5b868 用于记忆修订；柔和红 #ef817d 用于删除内容。
- 不使用渐变、霓虹光球、玻璃拟态、大面积纯黑、夸张阴影和卡片套卡片。
- 使用细边框、紧凑间距、清晰文字层级表达结构。
- 圆角克制：普通控件 6–8px，只有手机外壳使用大圆角。
- 字体感觉接近 Noto Sans SC + Space Grotesk，中文必须清晰可读，不能出现乱码或伪文字。

第一台手机：Workspaces / 会话总览
- 顶部显示 Memory Forge 与在线主机 REZVK-PC。
- 会话按“正在进行”“今天”分组。
- 每行显示 Provider 图标、真实会话标题、项目名、Git 分支、相对时间、运行中/待确认/空闲状态。
- 示例会话：Memory Forge 远程工作台、Paseo 移动端研究、Codex 会话索引修复、Grok 会话适配器。
- 底部导航为：会话、终端、提示词、设置。

第二台手机：Agent / 远程继续会话
- 顶部显示项目 memory-forge-rs、分支 feature/remote-foundation 和主机 REZVK-PC。
- 顶部有一个紧凑的会话页签下拉选择器。
- 中间显示用户消息、Codex 回复、Shell/Read 工具调用及成功状态。
- 增加 Memory Forge 独有的“记忆修订轨”：一条细琥珀色竖线和节点，标注“记忆已修订，可恢复”。
- 底部固定输入区，包含附件、模型 GPT-5.2 Codex、权限“工作区写入”和绿色发送按钮。

第三台手机：Memory / 修改审计与终端
- 顶部使用“记忆 / 文件 / 终端”分段控制。
- 默认展示记忆审计，不要默认展示普通代码 Diff。
- 显示本次会话 3 次修改，以及两组可读的 before/after 内容。
- 旧内容使用克制的红色底，新内容使用克制的绿色底。
- 每项带时间、复制和恢复操作。
- 体现 revision 防冲突、审计写入和可恢复的产品特征。

整体要求：
- 信息密度高但不拥挤，像成熟的生产力工具，而不是概念艺术。
- 所有文字都应位于容器内部，不溢出、不重叠。
- 不添加解释产品功能的营销文案。
- 不把界面做成通用聊天应用；必须让人一眼看出这是 AI 编程会话与记忆管理工具。
- 保留参考图中清晰的三屏信息架构，同时提升字重、对齐、状态层级和手机外壳质感。
```

如果 Gemini 对中文文字生成不稳定，追加：

```text
保持布局和视觉样式，允许减少正文数量，但所有保留的中文必须准确、清晰、可读。不要生成随机字符、乱码或无意义英文。
```
